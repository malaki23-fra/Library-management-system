# Community Library Management System

A React single-page application for a community library. It supports book catalogue management, stock availability, stock transactions with history, and library member management with membership-ID login. App data is stored in the browser's local storage.

## Run locally

1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the address printed by Vite.

## GitHub submission

Create a GitHub repository, then from this folder run:

```bash
git init
git add .
git commit -m "Complete community library management system"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

The membership login is a coursework demonstration using registered membership IDs; it does not use passwords or a server.
